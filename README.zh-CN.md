# 把授权接进自己的软件

1. 在自己的项目中用包管理器安装 SDK 0.11.0。Go 只需运行 `go get github.com/spf86/licentivo-sdk@v0.11.0`；其他语言使用官网快速开始中的对应安装命令或构建依赖。无需下载解压 SDK 源码包或设置本地源码路径。
2. 在控制台“产品”复制产品 ID，点击该产品的“签名公钥”，复制每一组密钥 ID、公钥，填入初始化代码的产品 ID 和受信公钥参数。快速接入也可以复制已填好的代码。
3. SDK 默认连接官网，不需要下载配置文件或先发布 1.0.0 版本。客户授权码由软件激活窗口读取，传给初始化函数的授权码参数。
4. 把自己的实际业务函数传给 RunFeature。按钮、快捷键、菜单等所有入口都必须经过该检查；未授权时不执行回调。
5. 测试允许、拒绝和重启恢复授权，再发布完成接入的软件，为每个客户签发独立许可证。退出时关闭客户端，SDK 保留绑定设备凭证。

快速示例先提供[可直接运行的 Windows 桌面程序](https://www.licentivo.com/zh/docs.html#example)，解压后双击 LicentivoExample.exe，无需安装编译器、CMake 或 .NET。源码单独提供，供按需学习和修改；Windows 主程序不超过 50 行。每位体验者独立领取三天测试许可证，自首次激活计时。普通导出允许，Pro 导出拒绝；重复下载不延长试用。

SDK 负责请求、设备识别、公钥验签、私有凭证和缓存、心跳；签名私钥和厂商管理 API Key 不进入客户软件。每个产品有自己的公钥，同一产品的客户共用公钥，各自的许可证和设备凭证分别管理。

完整示例见 QUICKSTART.md、EXAMPLE.md 和官网各语言 SDK 教程。版本限制、维护期、计次、浮动席位和离线文件授权是可选进阶功能。
