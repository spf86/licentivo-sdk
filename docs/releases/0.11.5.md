# Licentivo SDK 0.11.5

This release fixes authorization boundaries across Go, Java, C, C++, C#, Python, JavaScript, Rust and Ruby.

- Persist logout and local offline deactivation across process restarts. Failed credential writes cannot silently restore authorization.
- Reject stale offline approvals after logout or a newer request, while allowing safe import retries and distinct Launch identities.
- Preserve Launch connection, environment and identity when exporting offline requests from native SDKs.
- Enforce feature task deadlines and metering limits consistently, and support legacy signed grants that omit optional runtime policy fields.

Regression coverage includes nine-language process restart, offline request/import, logout, renewal, metering and deadline scenarios. Upgrade the server with the matching authorization fixes before distributing new clients.

Windows native state writes retry transient sharing violations for a bounded period, while persistent locks still fail without replacing the saved credential.
