# Licentivo SDK 0.11.1

The current client package covers Go, Java, C, C++, C#, Python, Node.js, Rust and
Ruby. It provides activation, signed feature checks, device credentials, policy
heartbeats, finite offline cache, floating seats, metered operations and explicit
logout. Install commands and package requirements are in [installation](../install.md)
and [supported runtimes](../support.md).

C/C++ applications use `find_package(Licentivo 0.11.1 REQUIRED)` and link
`Licentivo::C` or `Licentivo::CPP`. The exported dependency uses
`CURL::libcurl`. Match the application's compiler ABI, CPU architecture and
curl runtime/development files to the native package.

The application must supply its product ID and trusted public keys. A package
does not include a customer license or management credentials. Protect the actual
business entry point and verify denial, restart recovery and device release.
