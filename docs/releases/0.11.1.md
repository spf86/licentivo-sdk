# Licentivo SDK 0.11.1

Fix C and C++ CMake package consumption when the SDK was built with curl's
CMake config package and the application uses CMake's FindCURL module.
The installed SDK now resolves the exported curl dependency through the
consumer's public `CURL::libcurl` target. Applications can continue to use
`find_package(Licentivo 0.11.1 REQUIRED)` and link `Licentivo::C` or
`Licentivo::CPP` without creating compatibility aliases.

Independent consumer checks now build and run C and C++ in both curl
discovery modes, requiring the exact release version. Matching compiler,
architecture and curl runtime/development dependencies remain required.

The licensing protocol and client API are unchanged. Other language
packages retain their existing behavior and share the 0.11.1 release number.
