# Licentivo SDK 0.11.2

This security and reliability update covers all nine language integrations.

- Persist explicit logout in an independent, binding-scoped record when the ordinary cache journal cannot be replaced. Restart checks use the newest persisted decision.
- Refuse a logged-out Launch binding even when the old login obtains a different identity JWT. A real new login can authorize a new binding generation.
- Preserve another instance's newer credential and lease files during logout.
- Report failure when logout cannot be saved in either location, while immediately denying local protected work and continuing remote revocation attempts. Java and C# Deactivate also propagate that failure.
- Retire acknowledged unlink tickets from their original records without reviving authorization.

Use the matching current Licentivo server for Launch account mode. The server update also corrects policy-independent revocation, downgrade synchronization, manual limits on renewal, current-permission idempotent grants, and duplicate self-release allowance accounting. Existing downloaded offline grants remain subject to their signed expiry.

Packages and native builds are validated before publication. Public registry availability is verified separately; the website and release checksums identify the final published artifacts.
