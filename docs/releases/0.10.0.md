# Licentivo SDK 0.10.0

Release of the Go, Java, C, C++, C#, Python, Node.js, Rust and Ruby clients under the MIT license.

- Independent Go module: `github.com/spf86/licentivo-sdk`; the common installer automatically adds the verified local module and version requirement.
- Python wheel, Node.js npm archive, .NET NuGet package and Java JAR ready for package or project installation.
- CMake source integration and native C/C++ packages with separate compiler targets.
- Rust Cargo path installation and distributable crate; Ruby source and Windows/Linux precompiled platform gems.
- One version, PowerShell/Bash installers, a package manifest and SHA-256 checksums for all nine languages.
- Activation and restart examples, pinned signature verification, device credential storage, policy heartbeat, offline leases and metered-feature reservations.
- Release build and fresh-project installation checks run without a licensing server, database, customer data or payment transaction.

The [installation guide](https://www.licentivo.com/en/docs.html#sdk) lists verified public registry routes and pinned commands. Packages are also hosted at `https://www.licentivo.com/assets/sdk/releases/v0.10.0/`. The PowerShell/Bash installers support all nine languages. Immutable website staging requires a complete, verified package manifest before deployment.

## Public installation

| Client | Published package and installation |
| --- | --- |
| Go | `go get github.com/spf86/licentivo-sdk@v0.10.0` |
| Python | [PyPI](https://pypi.org/project/licentivo-sdk/0.10.0/) · `python -m pip install "licentivo-sdk==0.10.0"` |
| Node.js | [npm](https://www.npmjs.com/package/@licentivo/sdk/v/0.10.0) · `npm install @licentivo/sdk@0.10.0` |
| C# | [NuGet](https://www.nuget.org/packages/Licentivo.SDK/0.10.0) · `dotnet add package Licentivo.SDK --version 0.10.0` |
| Java | [Maven Central](https://central.sonatype.com/artifact/com.licentivo/licentivo-sdk) · `com.licentivo:licentivo-sdk:0.10.0` in Maven or Gradle |
| Rust | [crates.io](https://crates.io/crates/licentivo/0.10.0) · `cargo add licentivo@=0.10.0` |
| Ruby | [RubyGems](https://rubygems.org/gems/licentivo-sdk/versions/0.10.0) · `gem install licentivo-sdk --version 0.10.0` |
| C / C++ | Download a matching Linux x64, Windows MinGW or Windows MSVC CMake package below, then link `Licentivo::C` or `Licentivo::CPP` |

See the [SDK README](https://github.com/spf86/licentivo-sdk#readme) for feature behavior, requirements and a complete activation example. The [installation guide](https://www.licentivo.com/en/docs.html#sdk) provides Maven/Gradle declarations, Gemfile usage, system dependencies, the common installer and application integration examples in all nine languages.

Windows x64 and Linux x64 have execution evidence. Physical macOS and ARM64 acceptance are pending. This release does not contain dedicated Android or iOS SDKs. Native binary packages must match the application's compiler and ABI; build from source when they do not.

See `README.zh-CN.md` for Chinese instructions and `docs/install.md` for each language. Keep vendor API keys and private activation/device files out of client packages and Git.
