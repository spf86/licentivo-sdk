# Licentivo SDK 0.11.0

- Direct product ID, public signing keys and customer activation input in all
  nine bindings. The official HTTPS server is the default.
- Source downloads bake only public product settings into the application code;
  no product configuration file or test license secret is exported.
- Quick start guides integration into existing software. Quick example is a
  separate source application, with a Windows desktop entry under 50 lines.
- Public example visitors receive independent three-day licenses, starting at
  their first activation. Reclaim/download never extends the existing expiry.
- Ordinary export succeeds; Pro export is blocked before business execution.

## Install in your application

| Language | Install |
| --- | --- |
| Go | `go get github.com/spf86/licentivo-sdk@v0.11.0` |
| Python | `python -m pip install "licentivo-sdk==0.11.0"` |
| Node.js | `npm install @licentivo/sdk@0.11.0` |
| C# | `dotnet add package Licentivo.SDK --version 0.11.0` |
| Java | `com.licentivo:licentivo-sdk:0.11.0` in Maven or Gradle |
| Rust | `cargo add licentivo@=0.11.0` |
| Ruby | `gem install licentivo-sdk --version 0.11.0` |

C/C++ use the automatic, checksum-verified native package installer. The website
quick start uses these public installation routes and keeps the small source
application under the separate Quick example entry.
