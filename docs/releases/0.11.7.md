# Licentivo SDK 0.11.7

The nine SDKs now report readable device names and optional operating-system,
processor, memory, graphics, architecture and system-volume information. These
fields are display data; licensing identity and signature verification stay
unchanged. The matching server accepts the new fields and exposes device labels.

This release also fixes Java initialization when the optional device name is
absent, includes the shared device-information header in Rust and Ruby source
packages, and supports the ARM64 architecture constant with older MinGW headers.

Supported languages: Go, Java, C, C++, C#, Python, JavaScript, Rust and Ruby.
The SDK remains available under the MIT license.
