# Licentivo SDK 0.11.6

Fixes a macOS device-identity read that could be interrupted by a host runtime signal. The native core now preserves partial input and retries `EINTR`, keeping initialization and recovered device bindings stable. C, C++, Rust and Ruby share this core; authorization errors and genuine I/O failures still fail closed.

The regression covers interruptions at every byte boundary, partial lines, EOF and genuine read failures. Both macOS Intel and ARM passed 500 independent Ruby initializations with GC pressure and stable device identities. Native startup probes now wait for their background refresh to complete after checking that cached startup and feature reads remain responsive.

The wire protocol and authorization policy are unchanged.
