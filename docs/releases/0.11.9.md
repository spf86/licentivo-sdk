# Licentivo SDK 0.11.9

The Rust crate now includes an activation and feature-check example in its generated API documentation. The language guides show how to pass product signing keys and run a protected operation in Rust, Java, Node.js and Python.

Python metered-task tests now drive the renewal worker with a controlled clock. They verify renewal past the original deadline, recovery from a transient network error, single execution of the business callback and shutdown of the renewal worker.

Launch SDK 0.1.9 embeds this version for use with Launch server 0.3.10-beta. Check [package availability](0.11.9-links.json) before installing from a registry.
